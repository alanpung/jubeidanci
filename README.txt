A2 写作课程 + 评分修复 + 中文题目 sticky 钉顶（避开 64px 顶栏） — 文件清单
========================================================================
把本 zip 解压到你本地 jubeidanci 仓库的根目录（覆盖同名文件即可）。

移动端打字时的最终布局（修复了"只剩键盘"的 bug）：
- 根因：app 有 sticky top-0 z-30 h-16 (64px) 固定顶栏，之前 top-0 把中文卡盖在栏后、
  100dvh 又没减掉这 64px，导致输入框被推到键盘后。
- 现在：中文题目用 sticky top-16 (=64px) + z-40 + 不透明白底，正好钉在顶栏下方，
  页面随键盘上滚时中文始终可见；英文输入框在下方独立区域，互不重叠。
