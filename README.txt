A2 写作课程 + 评分修复 + 中文题目钉顶/英文框内部滚动 — 文件清单
============================================================
把本 zip 解压到你本地 jubeidanci 仓库的根目录（覆盖同名文件即可）。

移动端打字时的最终布局：
- 键盘弹出 → 整块变 h-[100dvh] 的 flex 纵向布局。
- 中文题目：shrink-0，钉在顶部，固定不动（太长自身可滚）。
- 英文输入框：flex-1 min-h-0 + overflow-y-auto，自己带内部滚动条。
- 两者分离，中文始终在顶部可见，无需手动上滑页面。
- 键盘弹出时隐藏标题/音频/导航以节省竖向空间。
