# 句背单词 (jubeidanci)

AI-powered English learning platform.

## Features

### Translation Courses

Pre-built courses at CEFR levels A1, A2, B1, B2, C1, C2:

- Number of SRS words per course are shown
- Chinese → English translation with accepted variants and SRS word tagging
- Progressive difficulty and thematic units (work, travel, academic, etc.)

### Spaced Repetition (SRS)

- SRS cards progress from New (N)→ Learning (L)→ Mastered (M).
- Words: Student can filter words by level, alphabet, POS and SRS Status.
- Progress: Student can check and monitor their own progress in vocabulary size.

### Interactive Exercises

- Flashcard
- Fill in the blank
- Translation
- Writing
- Multiple choice
- Word order
- Listening (TTS)
- Speaking (STT)
